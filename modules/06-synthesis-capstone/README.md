# Module 06: Synthesis Capstone

## The question this module answers

Given a context-behavior phenomenon nobody told you about, can you design and defend an original
empirical test of it?

## Where it sits in the arc

Sixth module, last of the arc. Prerequisite: all of Modules 01-05 - this capstone must genuinely
synthesize, not repeat. Its gate (below) is deliberately designed to require reusing Module 04's or
Module 05's methodology, not just Module 02/03's depth/length sweep pattern again, addressing a real
gap this workshop's own first Review Panel pass found in an earlier capstone draft (see
`docs/review-panel/2026-07-07-initial-design.md`'s Instructional Designer finding). See
[`modules/README.md`](../README.md) for the full arc and why this order.

## Learning objectives (placeholder: finalized when content is authored)

- Identify a context-behavior phenomenon this arc didn't explicitly cover (e.g. attention sink,
  distractor semantic similarity, multi-document order sensitivity) and frame it as a testable,
  single-variable question.
- Design and run an original scripted experiment against your own harness, reusing either Module
  04's pre/post-comparison methodology or Module 05's before/after-mitigation methodology as the
  measurement pattern, not inventing a third pattern from scratch or just re-running Module 02/03's
  sweep on a new variable.
- Defend, in writing, how the new finding connects back to at least one earlier module's own
  measured result - not just a restated finding wearing new variable names.

## Exercise material to draw from (not a spec: Coachgremlin authors the real exercise later)

Real material this module's exercise should be built from: candidate uncovered phenomena worth
scoping into a real prompt - attention sink effects, distractor semantic similarity to the needle
(a factor Chroma's report measured separately from position/length), and multi-document order
sensitivity in RAG-style contexts. See [`docs/workshop-design.md`](../../docs/workshop-design.md)'s
curriculum-anchor section for the underlying research these candidates are drawn from.

## Required gate (placeholder: shape decided now, real rubric written later)

- **Empirical tier.** The learner's original experiment must explicitly reuse Module 04's
  pre/post-comparison methodology or Module 05's before/after-mitigation methodology as its
  measurement pattern (not Module 02/03's depth/length sweep restated on a new variable), produces
  a real scored result, and stays within the workshop-wide cost guardrail (≤20 scripted invocations
  - see [`modules/README.md`](../README.md)).
- **Conceptual tier (Coachgremlin).** Confirms the written defense draws a genuine, checkable
  connection between the new finding and at least one earlier module's own measured result - e.g.
  "this behaves like Module 03's length-driven rot because X, not just because both curves go down"
  - rather than a restated finding wearing new variable names.

## Takeaway

A personal context-diagnosis playbook compressing the whole arc into one checklist, built from a
defended original experiment, not a substitute for it. Packaged by Coachgremlin once the rubric is
met.

## Stop condition (placeholder)

The learner's original experiment clears the empirical tier (real measurement, correct methodology
reuse, within the cost guardrail) and Coachgremlin confirms the written defense genuinely connects
to an earlier module's result. Reading this page does not count: advancement requires a real,
original, defended experiment.
