| 2026-07-07 | Drafted `docs/workshop-design.md`: 6-module arc (Window Mechanics → Positional Bias → Context Rot at Scale → Compaction Mechanics → Mitigations → Synthesis capstone) | Anchored to real canonical material researched this session: Lost in the Middle (Liu et al. 2023/2024), Kamradt's needle-in-a-haystack methodology, Chroma's Context Rot report (2025), Anthropic's "Effective context engineering for AI agents" (2025), and Claude Code's real `/compact` mechanism. Teaching method is harness-first empirical measurement (scripted Claude Code CLI/SDK runs, never raw API scripts), with a two-tier gate (empirical measurement primary, Coachgremlin conceptual tier secondary) — this workshop's equivalent of `borrow-native`'s compiler/clippy gate, built from scratch since this subject has no existing objective-checker tool. |
| 2026-07-07 | Ran first Workshop Review Panel pass (7 personas) against `docs/workshop-design.md`; applied the cheap text-only fixes, deferred structural findings to Task 4 | Full report: `docs/review-panel/2026-07-07-initial-design.md`. Applied now: fixed needle-in-a-haystack citation (was linked to an Arize fork, not Kamradt's original — confirmed via `gh api`), softened "gives context rot its name" to "popularized," corrected the `/compact` mechanism citation and dropped an unverifiable ~95% trigger figure (official Claude Code docs describe the mechanism qualitatively, not as a fixed percentage), standardized "compaction" terminology (module title was "Compaction & Compression Mechanics"), and added an explicit Half-Life-vs-Context-Rot naming rationale to resolve a self-contradiction the Technical Writer persona flagged. **Not actioned:** the naming decision itself (human-picked, out of scope for this panel to reopen) and em-dash/voice-consistency cleanup (deferred to the brand-layer pass, same as `borrow-native`'s "voice-finding handoff" pattern). **Deferred to Task 4 (module skeleton):** making the empirical-tier gate concrete for all 6 modules (only 02/04 have one today), a cost/scope bound for scripted parameter-sweep exercises, a null-result contingency for Module 02, and giving the capstone a task that demonstrably requires Modules 04-05. |
| 2026-07-08 | Built module skeleton (`modules/`, 8-part template per module), brand layer (`docs/brand.md`), maintainers split (`docs/maintainers.md`), and Docs Consistency Loop (`check-brand-lint.sh` wired into pre-push) | Directly addressed every structural finding deferred from the 2026-07-07 Review Panel pass: each of the 6 modules now states a concrete empirical-tier threshold (not just 2 of 6), a workshop-wide cost/scope guardrail (≤20 scripted invocations per module, synthetic-only haystack content) is stated in `modules/README.md`, Module 02's gate explicitly treats a flat/null result as valid, and the capstone's gate requires reusing Module 04's or Module 05's methodology rather than repeating Module 02/03's sweep pattern. Brand lint clean on first run after fixing an em-dash habit across all 6 module files (caught by the lint script itself, not manual review). |
| 2026-07-08 | Re-ran the Workshop Review Panel (7 personas) against the new module skeleton/brand layer/README, applied all 10 findings | Full report: `docs/review-panel/2026-07-08-module-skeleton.md`. Also confirmed: this pass validated that the empirical-tier gate is only a true outcome-threshold for Module 01 — Modules 02/03/05/06 deliberately gate on procedure/completeness by design, a nuance the original 2026-07-07 triage didn't distinguish; recorded here rather than treated as a defect. |
